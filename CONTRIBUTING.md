# Contributing

This is a personal home lab used to practice networking, systems administration and offensive security. It isn't an open collaborative project, but suggestions, corrections and questions are welcome.

## Reporting an issue

If you spot a config error, a factual mistake in the documentation, or a security concern in how something is described, please open an issue with:

- Which file is affected (`README.md`, a config under `Appliances configs/`, etc.)
- What's wrong, and what you'd expect instead
- Any relevant command output or reference, if applicable

## Suggesting a change

Pull requests are welcome for:

- Documentation fixes or clarifications
- Config hardening suggestions (ACLs, routing, switch security, etc.)
- Diagram or structure improvements

Please **do not** submit PRs containing real credentials, API keys, or other secrets. Use placeholders like `[TARGET_IP]` or `[USERNAME]` in examples.

## Scope

Out of scope for this repo: unrelated tooling, generic networking tutorials, or anything not tied to this specific lab's topology and configs. Keep changes focused on what's documented here.

## Code of conduct

Be respectful and constructive. This is a learning project — questions and "why did you do it this way" discussions are genuinely welcome. 😉
